# `else if` chains are not defined

- 状態: 未解決
- 日付: 2026-11-01

## Situation

spec §1.1.3 defines only `if c { a } else { b }`. Whether `else` may be
followed directly by another `if` — `if a {x} else if b {y} else {z}` —
is not stated.

The grammar takes the spec-literal reading: `else` requires a block, so
a chain needs `else { if b {y} else {z} }`. Nested ifs work fine
semantically; only the flat sugar is missing.

## Why it is a problem

`else if` is nearly universal in C-family and Rust-family languages; if
it is intended, the grammar production
`"else" ( if-expr | block )` must change. If it is not intended, spec
should probably note that `else { if ... }` is the way.

## Possible responses

- Add `"else" if-expr` to the grammar (a one-word spec change)
- Or confirm the block-only form
