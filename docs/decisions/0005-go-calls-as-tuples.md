# 0005 Go 関数は Go の書き方で呼び、型は自動で取り込む

- 状態: 採用
- 日付: 2026-11-01

## 背景

Go の関数は素直に呼びたい。カリー化した並置の呼び出しや、型付きの `extern` 宣言を毎回書くのは負担が大きい。

## 決定

- n 引数の Go 関数は、Gom からは n 要素のタプルを 1 つ受け取る関数に見える。`f(a, b)` は並置の適用 `f (a, b)` そのものなので、新しい構文は要らない。Go 関数はカリー化しない
- メソッド呼び出しは `x.M(args)`
- `import go` で、コンパイラが `go/packages` と `go/types` から型を自動で取り込む
- `extern` は自動の対応付けを上書きするときだけ書く
- `(T, error)` は `Result T GoError`、`(T, bool)` は `Option T` に対応させる

## 影響

- 補助ツール `kumo bind`（旧案）は不要になった
- `*T` の既定（`Ptr T` か `Option (Ptr T)` か）と、Go へ渡す `List` のコピーは未決
- 部分適用ができない問題は 0006 で解決した

## 追記

- `(T, bool)` を `Option T` に自動変換する規則と、数値型の自動変換の規則は 0019 で置き換えた
