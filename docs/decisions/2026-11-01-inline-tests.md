# テストは実装と同じファイルに書く

- 状態: 採用
- 日付: 2026-11-01

## 背景

Rust のように、テストを実装と同じファイルに書きたい。分離はトランスパイルの時点で行えばよい。

## 決定

- `test "名前" { ... }` をトップレベルに書く。補助定義には `@test` を付ける
- `gom build` ではテストを取り除き、`gom test` のときだけ `_test.go` として出力する
- テストは同じ Go パッケージに入るので、非公開の定義も呼べる
- `gom build` でもテストの型検査とパターン検査は行う

## 影響

- テストはインターフェースのハッシュに含めない
- 結果は `go test -json` から変換し、`kind: "test"` の JSON メッセージとして出す
- `assert_eq` のために、値の表示関数をコンパイラが全型に自動生成する
