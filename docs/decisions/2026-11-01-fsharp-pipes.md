# F# 流のパイプと関数合成

- 状態: 採用
- 日付: 2026-11-01

## 背景

長い関数適用の折り返しを括弧だけで行うのは読みにくい。

## 決定

- `|>`、`<|`、`>>`、`<<` を F# と同じ意味で持つ。二項演算子の中で最も優先順位が低く、左結合
- 長い処理はパイプで上から下へ流して書くのを基本の書き方にする
- 行頭の `|>` は前の行へ、行末の `<|` は次の行へ続く
- パイプで書けない長い関数適用だけは括弧で折り返す

## 影響

- パイプは脱糖で普通の適用に戻すので、生成コードにクロージャは残らない
- 失敗し得る処理用の `|?>` を追加した（[result-pipe-auto-wrap](2026-11-01-result-pipe-auto-wrap.md)）
