# `select` の腕は Go と同じくランダムに選ぶ

- 状態: 採用
- 日付: 2026-11-04

## Context

open-questions: 「`select` の腕の選び方: Go と同じくランダムに選ぶままにするか、優先度付きの書き方を用意するか」。spec 10 章は各腕が Go の `select` の 1 つの `case` にそのまま対応すると定めている。

## Decision

複数の腕が同時に準備できているときは、Go と同じく一様ランダムに 1 つ選ぶ。優先度付きの構文は入れない。優先したい場合は `default` 付きの `select` を入れ子にして書く（Go と同じ書き方）。spec 10 章に明記する。

## Alternatives

- *優先度付きの腕（ソース順優先など）*: Go の `select` に直接対応しなくなり、生成コードが入れ子の select やループに展開される。腕と `case` の 1 対 1 対応（読める生成コード）を崩すほどの需要は観測されていない。
