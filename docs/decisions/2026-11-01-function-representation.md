# 関数値の表現

- 状態: 未決（P0 の実験で決定）
- 日付: 2026-11-01

## 決まったこと

- 多相な定義と、実行時の関数値を IR 上で区別する。多相な定義を値として使う箇所で型引数を具体化し、そのあとで arity を調整して Go の関数やクロージャにする

```
多相な定義 ─(型引数の具体化)→ 単相の関数値 ─(arity の調整)→ Go の関数 / クロージャ
```

- 既知の関数への引数が揃った呼び出しは、Go の多引数呼び出しに直接変換する（[juxtaposition-and-currying](2026-11-01-juxtaposition-and-currying.md) のとおり）

## P0 で決めること

- 関数値をカリー化形 `func(A) func(B) C` で持つか、arity 付きのクロージャで多引数のまま持つか
- 部分適用した値の型の具体化の時点
- パッケージをまたいで関数値を公開するときの Go 側の形
- ラベル付き引数の部分適用を Go の関数値にどう落とすか
