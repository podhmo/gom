# 値の表現（ADT・List・Result）

- 状態: 一部採用、一部未決（P0 の実験で決定）
- 日付: 2026-11-01

## 決まったこと

- `List a` の意味: 不変の値として扱うシーケンス。Go のスライスとの境界では両方向ともコピーする。コピーを避けたいときは Go が所有する可変の `Go.Slice a` を使う
- `Array a` は Gom の可変配列
- ADT の網羅性が保証するのは、Gom の中で作られた値だけ。Go から渡された不正値（`nil` など）は契約違反とし、`match` で型名を含むメッセージで panic する

## P0 で決めること

| 対象 | 比較する案 | 見るもの |
| --- | --- | --- |
| ADT | sealed interface / タグ付きの単一 struct | ジェネリクスとの相性、割り当て、Go からの使いやすさ、`nil` |
| `List` | スライスベース / 永続 cons リスト | 先頭追加、`[x, ..rest]` のメモリ保持、Go との変換コスト |
| `Result` | sealed interface / `struct { Value T; Error E; Ok bool }` | 構築コスト、大きな値型のコピー、ゼロ値、`(T, error)` との変換 |

スライスベースの `List` にする場合は、cons リストの性能特性（O(1) の先頭追加）を期待させない仕様にする。
