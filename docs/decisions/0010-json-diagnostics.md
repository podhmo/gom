# 0010 コンパイラのメッセージは既定で JSON

- 状態: 採用
- 日付: 2026-11-01

## 背景

コンパイラのメッセージ（エラー・警告・注記・集計）は、AI エージェントが読み込んで使うことを第一に想定する。

## 決定

- 既定で JSON Lines を標準出力に書く。人間向けの表示は `--format text`
- 最後の行は必ず `summary`。終了コードは成功 0、診断エラー 1、内部エラー 2
- `message` は 1 行の英語。詳細は `data` に構造化して入れ、AI が文言を解析しなくて済むようにする
- 機械的に適用できる修正候補 `fixes` を付け、安全度を `safe` / `placeholder` / `unsafe` で示す
- エラーコードは安定させ、再利用しない
- 生成した Go コードの `go build` / `go vet` のエラーも `.gom` の位置に戻して同じ形式で出す

## 影響

- M1 から JSON で出す（後から足すより楽なため）
- 独自スキーマのままにするか、LSP / SARIF に寄せるかは未決

## 追記

- 診断はコンパイラ内部のデータ型を正とし、JSON・text・LSP はそこからの変換にする（0021）
- 位置の正は UTF-8 のバイトオフセット。行・列や UTF-16 の位置は出力時に計算する
