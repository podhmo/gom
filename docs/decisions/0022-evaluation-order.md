# 0022 評価順序

- 状態: 採用
- 日付: 2026-11-01

## 決定

- 関数適用の引数は、ソースに書かれた順（左から右）に評価する。ラベル付き引数の並べ替えは評価順を変えない
- Go 呼び出しの `_` プレースホルダは、`_` 以外の引数を関数を作る時点で 1 回だけ評価する（0006）
- パイプ `x |> f y` は `x` を先に、次に `f y` を評価する
- `select` は入った時点で、すべての腕のチャネル式と送信値をソース順に 1 回ずつ評価する（Go と同じ）
- `try` と `|?>` は、`Err` を見た時点で以降の評価を行わずに脱出する
- Gom 側の変形によって、Go と副作用の実行回数が変わってはならない

## 影響

- 意味論の比較テスト（小さな評価器と生成コードの比較）で、評価順を検証する
