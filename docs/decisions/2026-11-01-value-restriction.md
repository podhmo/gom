# 一般化は value restriction 付き

- 状態: 採用
- 日付: 2026-11-01

## 背景

トップレベルを常に一般化すると、`let r = Ref.new []` のような値束縛が多相になり、可変参照によって型安全性が壊れる。

## 決定

- トップレベルの定義は、右辺が関数か構文的な値（リテラル、コンストラクタの適用、それらからなるタプル・リスト・レコード）のときだけ一般化する
- ローカルの `let` は一般化しない。これは実装上の一時的な制限ではなく、v1 の型規則とする

## 影響

- 将来ローカル多相を入れる場合は relaxed value restriction を検討する（future work）
