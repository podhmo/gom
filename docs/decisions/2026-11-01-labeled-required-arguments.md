# ラベル付き必須引数

- 状態: 採用
- 日付: 2026-11-01

## 背景

送金元と送金先のような、同じ型で取り違えやすい引数を型検査で守りたい。

## 決定

- `(~to: Account)` で宣言し、`~to: bob` で渡す。ラベルの指定は必須
- 省略可能引数（OCaml の `?x`）とデフォルト値は持たない
- ラベル付きの呼び出しは、その時点で関数の型が既知であることを要求する
- ラベル付き関数とラベルなし関数の暗黙変換はしない
- 渡す値がラベルと同名の変数なら `~to` とだけ書ける（OCaml と同じパンニング）

## 却下・保留した案

- OCaml のように型推論とラベルを組み合わせる: 曖昧さが生じるため v1 では採らない
- 制限の緩和と省略可能引数は future work

## 影響

- ラベルは関数型の一部になる。Go 側ではラベルを消去し、ラベル名がそのまま Go の引数名になる
- ラベルを先に渡せば位置引数だけの関数になるので、高階関数にも渡しやすい
