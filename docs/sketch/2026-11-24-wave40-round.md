## #188 のレビュー修正（round 2: 7 件、round 3: 1 件）

- 全腕 catch-all の match が case 0 の DSwitch を生成し validator に
  落ちる（`_ : Go.Any -> 1` 単独で build 失敗）→ case 0 なら default
  tree をそのまま返す
- `GoRepr` の Func case が param を二重描画（入れ子で 2^n）→ 一回化
- `flatSig` が gom-adapted sig（`error`→`Result`）を reflect の
  `func() error` と比較して miss → `InterfaceMethod.GoSig` に
  raw sig を載せる。reflect 綴り再現のため `goTypeSpell`
  （alias 展開・byte→uint8・any→`interface {}`・named は
  `pkgbase.Name`）+ reflect parity テスト
- `p : Go.Any` catch-all の bind が box を落として空 `List Int` を
  `List[any]` 扱い → `any` grain では box を保持
- typed-nil error payload の bind で `Error()` を呼び panic →
  reflect nil 判定で host のまま bind
- shadowed generic の args が未正規化で `List Char`/`List Int32` の
  dup を見逃す → `CanonGoRepr` 化（spec fixture 追加）
- tree-sitter が裸 arrow target を受理 → `app_type` に制限
- 名前付き単一結果 `Lookup(string) (ok bool)` が
  `func(string) (bool)` となり reflect の `func(string) bool` と
  不一致 → 結果名を無視
