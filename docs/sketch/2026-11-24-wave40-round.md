## 学び（pitfalls）

- **reflect と文字列比較する面には raw signature が要る**:
  gom-adapted 名（`error` → `Result` 変換など）で interface メソッドを
  比較すると必ず miss する。`InterfaceMethod.GoSig` に生 sig を載せ、
  綴りは reflect-faithful（alias 展開・byte→uint8・any→
  `interface {}`・結果名を捨てる）にしないと `func() bool` vs
  `func() (bool)` のような差で落ちる
- **catch-all 腕の bind は box を保持する**: `p : Go.Any` や
  typed-nil error の bind で payload を取り出そうとすると、box の
  記録型を失ったり typed nil のメソッドを呼んで panic したりする。
  `any` grain / nil-able な grain では host 値をそのまま渡す
- **型の同一性判定は emit される Go 表現でやる**: `Char` と `Int32`、
  `List Char` と `List Int32` は Go では同じ `case` なので
  source 側の綴りで dedupe すると取り逃す。判定前に `CanonGoRepr`
  まで正規化する
- **case 0 の type switch は emit しない**: 全腕が default に落ちる
  match で case 0 の DSwitch を生成すると IR validator に落ちる —
  default tree をそのまま返す
- **tree-sitter grammar も構文変更の対象**: `.gom` の grammar 制約を
  変えたら `tree-sitter-gom/grammar.js` と corpus も同期する
  （裸 arrow target の受理漏れ）
