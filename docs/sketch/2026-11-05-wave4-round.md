## What shipped

- **P2-2c**: eligible function-valued aggregate bindings lower to
  named `ValueAlias` wrappers so `let (again, _) = (count, 0)`-style
  recursive function values compile; residual illegal cycles are
  rejected with E0907. Eager initializer effects are preserved via
  hidden eager `VarDecl`s (`initNeedsEval`, `aliasInit`).
- **P3-5**: `extern` declarations override Go binding signatures —
  `Option` for pointer/comma-ok results, `Result` for `(T, error)`,
  pair for `(A, B)`, plus a Unit spelling for zero-argument Go
  functions. The bad extern-arity diagnostic had two roots (imported
  `flag.String` shadowing the builtin; `symTypeCtor` accepting value
  symbols in type position) — both fixed. E0509 gained structured
  `member`/`declared`/`go` fields.
- **P3-4**: Go method calls and the cute `_` placeholder. Member
  application on not-yet-typed receivers defers through
  `pendingSels`/`pendingApplies` and replays once the receiver type
  resolves; hole arguments convert at invocation time while
  non-hole arguments keep creation-time evaluation.
- **V-6**: a package spanning multiple `.gom` files is one
  resolve/check unit (`resolve.Files`/`check.Files`/
  `build.CompileFiles`); sibling functions, types, constructors and
  top-level lets are order-independent. `gom check`/`build`/`test`/
  `fix` run on the package unit; consumers import via `.gomi`
  (`internal/gomimport`). Package-scope hidden temporaries carry a
  per-file tag (`tmp<N>_<fnv32(path)>`) so sibling files cannot
  redeclare the same generated identifier.

## Incidents worth recording

- **Rate limits**: P2-2c's implementer and V-6's first reviewer hit
  model rate limits mid-run. The interrupted work was committed as
  WIP (`ae20f85`) before resume; both completed after the reset.
  Lesson: commit partial state before resuming rate-limited agents.
- **Semantic merge conflict** (P3-4 × P3-5): P3-4's checker test
  stubs bound type names with `gofnSym` (KindFunc). P3-5's tightened
  `symTypeCtor` gate correctly emits E0201 for value symbols in type
  position, so the merge turned eight fixtures red. Fixed by binding
  type names with `gotypeSym` — the merge exposed wrong test
  helpers, not a compiler bug.
- **Cross-task coupling** (P2-2c × V-6): V-6's `pkgTmp()` tags
  package-scope temporaries; P2-2c's `discardDecl`/`aliasInit`
  paths also mint package-scope temps and needed `pkgTmp()` too.
  Resolving the `lower.go` conflict by composing both helpers kept
  eager semantics and collision-freedom; regenerating
  `aggregate_function_alias.golden.go` captured the tagged names.
- **Review found real defects twice before merge**: P2-2c's
  `let g = { …; f }` dropped the initializer (eager-semantics
  violation), and V-6's per-file `l.tmp()` redeclared package temps
  across sibling files. Both were fixed by the implementer and
  re-verified before merge — the review gate is doing its job.

## Residual boundaries (recorded, not evaded)

Open work is tracked rather than merged silently:

- `checkInitCycles` is file-local while Go initialization is
  package-wide — recorded in implementation-gaps.md; more relevant
  now that packages are the compile unit.
- `docs/spec.md` has no package initialization-order section, so
  E0907's Spec reference is not fully grounded.
- `gom build` may still write output when E0601 `.gomi`
  conformance fails after codegen.
- Exported `let foo` vs `type Foo` collide in the Go namespace even
  in single-file packages.
- Same-named `test` blocks in sibling files produce duplicate Go
  test functions.
- `pkg.Type.Ctor` member spelling, `.gom`↔`.gom` import cycle
  detection, and `gom dump` on multi-file packages — grouped as the
  "V-6 残件" TODO entry.
- Method-chain `x.M(1).N(2)` binds wrongly (parenthesize to work
  around); eval lacks `..e` spread in Go-call arguments; any-hole
  deferred diagnostics differ from eager ones; multi-file eval is
  an open question in `docs/open-questions.md`.
- Standard-library bindings remain a task distinct from the extern
  override mechanism.
