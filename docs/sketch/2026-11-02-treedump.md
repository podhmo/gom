# Verification report: IR text dumper internal/treedump (B-6)

- 日付: 2026-11-02
- 目的: B-6「中間表現の安定テキストダンプ」の実装が、ゴールデン比較に必要な決定性と網羅性を満たすことを確認する
- 関連: [decision: treedump-format](../decisions/2026-11-02-treedump-format.md)（draft）、TODO B-6、design.md 2 章

The `internal/treedump` package (doc.go, treedump.go, syntax.go,
typed.go) and its tests (treedump_test.go, syntax_test.go,
resolve_test.go, typed_test.go) are the prototype for the draft
decision. The public surface is four functions:

```go
DumpSyntax(f *syntax.File) string     // phase 2 output + trivia
DumpResolved(r *resolve.Resolved) string // phase 3 output + Defs/Uses
DumpTyped(f *check.File) string       // phase 4 output + types + CallInfo
DumpType(t types.Type) string         // types.Type.String() atom
```

## What was verified

- **Coverage** — every node of each IR is dumped:
  - `syntax`: all 6 Decl variants (incl. ExternDecl entries, doc
    comments), all 4 TypeBody variants, all 6 TypeExpr variants, all
    9 Pat variants, all 23 Expr variants, both StrPart variants, all
    3 SelectArm variants, File.Package/Decls/Comments/Blanks.
  - `resolve`: the shared surface File plus the two side tables.
  - `check`: all 4 Decl variants, all 4 TypeBody variants (SumType /
    RecordType / AliasType / AbstractType), all 23 Expr variants, all
    9 Pat variants, StrPart, SelectArm, File.Imports.
  - Every sealed-interface type switch ends with
    `default: panic("unreachable")`; `scripts/check-sumtype.sh`
    passes over the package (via `make check`).

- **Determinism** — the two properties golden tests need:
  - `TestDeterminism` rebuilds `Resolved.Defs`/`Uses` in reverse
    insertion order and asserts byte-equal output, then dumps the
    same value ten more times; `TestTypedDeterminism` does the same
    for a typed file.
  - Map-derived sections (`(defs)`, `(uses)`) are sorted by key span
    then name; the `(syms)` section follows interning order which is
    itself a pure function of the traversal.
  - Symbol numbering follows first-encounter order in *source*
    order: this required interning a declaration's own symbol before
    walking its body (`type`/`variant`/`member` each had a case
    where children were built first and `Circle`/`radius`/`Write`
    came out misnumbered — caught by the golden test, fixed by
    computing the head text before building kids).

- **Format** — verified against the conventions in the decision:
  `@start:end` spans, `name%<n>` symbols with a `(syms)` table
  (`def@span`, `:pkg`, `:go`, `:test` flags), `:T` annotations
  parenthesized only when the type rendering has spaces, `->` for
  name-to-symbol resolution, `~label`/`:pun`/`:rest`/`:conv`/`:test`
  markers, `'a` type variables, `io%1.Reader%2` qualified names with
  both identifiers resolved.

- **CallInfo** — all nine fields appear in `(call ...)`: kind,
  `callee=`, `arity=`, `applied=`, `unapplied=`, `argtoparam=[...]`,
  `hole=`, `variadic`, `targs=[...]`; zero-valued optional fields are
  omitted and `-1` HoleIndex stays hidden (0 is a real index).

- **Escaping** — `atom` quotes only tokens that would break the
  single-token reading (spaces, parens, quotes, backslashes) via
  `strconv.Quote`; `quote` always quotes string payloads. Covered by
  `TestAtomEscaping` incl. empty string, UTF-8, and embedded newline.

- **Trivia** — free comments (`(comment@sp line " header")`) and
  blank lines (`(blank@30:31)`) merge into the decl stream by
  position; doc comments ride inside their decl/variant/extern entry
  as `(doc@sp "...")`.

- **Malformed input stays visible** — a nil symbol renders `?%`
  (`use@22:23 -> ?%`), a nil type `:?`, a nil package name ` -`;
  nothing silently drops.
