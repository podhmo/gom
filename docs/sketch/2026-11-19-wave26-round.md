## 引き継ぎ

- CI は push-to-main / PR-to-main synchronize のみ — チェーン PR
  は Devin Review のみ。マージは podhmo が retarget →
  `gh pr merge --merge` を下から順に。
- 遅延 RHS は finalize 時点では境界スタック・test フラグ・
  型変数スコープが既に空 — 遅延系を増やすときは `assignTarget`
  同様コンテキスト捕捉が必要（`checkAssignRHS` が参照実装）。
- `&&`/`||` のオペランドは生成コードで eager 評価される。
  決定的な比較・再帰は `if` 式で書く（stdlib/cmp の composer が
  参照実装）。
- `testdata/spec` の fixture は package 宣言が `main` でも動くが
  `ex` には `ex.gomi` が要る — 手元の `gom check` は
  `/tmp/gomfix`（go.mod + replace）配下でしか走らない。
