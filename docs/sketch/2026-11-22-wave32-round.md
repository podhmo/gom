## Devin Review の往復

- #129 (3 件): `//gom:allow` の語境界（`//gom:allowX` 誤認）、cache が
  `//gom:` 行を差分検知しない、cache が `--strict` を無視 — 全修正
- #130 (1 件): `unfilledLabels` が `fnSig` の入れ子 Ret を見落とす — Ret
  チェーンを辿る実装に修正
- #131 (2 件): 実装時に補完した `Scope.defer` 系の `escapes` flag は
  誤り — cleanup は scope 保持なので保守的 escaping が正しく flag は
  外してコメントで根拠を残した。`let x = cl` 経由の escape が
  パラメータに伝わらない alias 抜けは `bindOf` で修復

## 実装で発見したずれ（台帳 [x]）

- `let` 束縛ラムダ経由の E0419 偽陽性 — `let` 束縛 callee の
  パラメータ escape flag を推論（`argEscapes`）し、束縛エイリアス
  経由の danger 伝播（`bindOf`）で alias 抜けも塞いだ
- `Scope.defer` 系の `escapes` 未指定はずれではない（cleanup 保持の
  ため保守的 escaping が正しい）— review で補完を却下し根拠を明記
