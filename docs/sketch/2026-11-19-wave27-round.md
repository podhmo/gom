## 引き継ぎ

- CI は push-to-main / PR-to-main synchronize のみ — チェーン PR
  は Devin Review のみ。マージは podhmo が retarget →
  `gh pr merge --merge` を下から順に。
- `checkAssign` の早期 return 経路は `unit()` を返して RHS を
  捨てる — その検査が mint した meta は `quietMetasIn` で
  quiet にしないと E0407 が残る（deferred 経路は
  `dropDeferredOn` が面倒を見る）。dead work を増やすたびに
  この対称性を確認する。
- gomtest のディレクトリ case は bare `expected.json` /
  `golden.go` / `case.json` のどれかが無いと**各ファイル個別
  ケース**になる — `a.golden.go` などの member 名マーカは
  数えない。複数ファイルを 1 ケースにするなら `case.json {}`
  を置く。
- tree-sitter-cli は 0.27.1/0.26.3 がこの VM では GLIBC 不足で
  動かない。`npm exec --yes --package=tree-sitter-cli@0.25.10
  -- tree-sitter generate` で再生成（ABI 15 は不変）。
- lane B で新しい E0412 経路を足した: lambda の注釈スコープ
  変数は (a) 外側シグネチャの変数解決（owned でない）、
  (b) top-level let の generalization で TypeParams 採用、
  (c) それ以外は E0412 の 3 分岐。dedupe は `reportedUnbound`。
