## 学び・次への申し送り

- check の select 遅延解決は「`types.Chase(recv.Type())` が裸 `*types.Meta`」のときだけ `pendingSels` 行き — `Ptr ?1`（Con の引数にメタ）は**遅延されず** E0401 が先に出る。真の遅延代入ケースはラムダ param 経由（`(fn p -> p.N = 9) b`）
- `core.FieldGet` は Atom — select-path レシーバが値式より後に書き出されると recv が未バインドになる。lower は非 `*core.Var` の recv atom を先に `tmpBind` で束縛する必要がある（BUG_0001 修正）
- `decisionsdoc.ParseDecision` は `fieldRe` に一致する行しか読まない — `Supersedes:` の複数リンクは 1 行に集約しないと index で漏れる（#73 finding）
- golden harness（`goldenGenerate`）は `Loader` に goimport だけを通す — 普通の `import` を含む fixture は golden ではなく `testdata/spec/` に置く（specCompile は gomimport を配線済み）
- `Byte` には `<` が無い（E0401「ordered type」）— Ord インスタンスは byte には提供しない
- TestRepoFiles の format roundtrip は doc コメント結合を見る — `///` ブロックが連続すると 1 つの decl doc に merge されるので、モジュール doc 相当は最初の宣言の `///` に同居させる
