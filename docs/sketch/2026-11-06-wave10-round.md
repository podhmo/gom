## What shipped

  bug — `f ~b: "x"` silently collapsing to positional `f("x")` —
  is resolved by *extending* the meaning rather than rejecting:
  labels naming a returned function's param eta-expand across the
  curried chain (`f ~b: "x"` = `fn a -> f a ~b: "x"`).
  `ArgToParam` is now a flat-domain mapping; `classMappedCall`
  (exported as `ClassMappedCall`) classifies filled positions by
  declared-level prefix into `CallDirect`/`CallPartial`, shared by

  [label-args-into-returned-functions](../decisions/2026-11-06-label-args-into-returned-functions.md);
  verification sketch same date.

## Review findings worth recording

- **Fresh-eyes review caught a real blocker in the worker's own
  domain (third wave running)**: lane 1's `appendArg` promoted
  `CallPartial → CallDirect` on the stale arity-domain check
  `Applied >= Arity`. Post flat-mapping, `x |> g ~c:7` (g's
  returned fn takes `~c` past a positional `b`) promoted to
  CallDirect → emitted `g(x)(7)` binding `7` to `b` — an
  eval/compiled divergence in exactly the "call convention lies"
  class the lane existed to close. Fix shared `classMappedCall`'s
  flat-prefix rule; a latent malformed-mapping bug ([0]-length-1
  mapping for positional-only partials) surfaced in the same fix.
- **Reviewers verified mechanisms, not just diffs — and caught a
  wrong suspicion**: lane 2's worker claimed E0410/E0411
  reachable, contradicting the TODO's "possibly unreachable";
  reviewer traced both mechanisms to concrete fixtures (occurs
  conflict E0401+E0410 co-pin; E0411+E0407 co-pin). Claims were
  right, mechanism proofs now pinned.
- **Semantic merge conflicts beat textual ones**: (i)
  `bindGoStubs` signature change (lane 4) vs new call site
  written against the old one (lane 1) — auto-merged, `go vet`
  caught it; (ii) lane 1's generalized `payloadNilGuard` vs
  main's new `nilguard_test.go` `GoSig` literals — predicted by
  the reviewer, resolved with `ResNilable` at merge. Lesson:
  prompt reviewers for post-merge *semantic* breakage, not just
  textual conflicts — it worked twice.
- **Incident: user-side `gom build` artifact almost merged.** An
  interactive `gom build` inside `stdlib/list/` regenerated
  `list.go` with basename input → `SelfPath` returns `""` →
  self-importing output (`package list` importing `stdlib/list`,
  go-build-impossible). `git add -A` staged it silently; `go vet`
  caught the import cycle before commit. Recorded on the existing
  `SelfImportPath` gaps entry — pre-existing footgun, not wave-10
  fallout. Takeaway for orchestrators: `git add -A` during merge
  prep sweeps *any* dirty file — prefer staging conflict paths
  explicitly, and treat `go vet` import-cycle errors as
  suspect-artifact signals.
- **Rate-limit death recurred once** (lane 4 reviewer). Resume
  after the reset window completed cleanly — the
  resume-first playbook holds (no WIP salvage needed for
  read-only agents).
