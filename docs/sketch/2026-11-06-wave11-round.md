## What shipped

- **check-residuals (a): Go nullary function values ADOPTED.**
  `let f = e.Error; f ()` applies a `-> T` value with `()` as a call
  marker (`CallUnknown` `Applied:0`); deferred `m ()` on a pendingSel
  stays on the Gom replay path via `pendingApply.alwaysGom` (a Go
  `CallGo` cannot name a receiver through a Var callee); lower emits
  the 0-arg `CallFunc`, eval agrees through the bound builtin.
  spec §8.1 updated. Decision:
  [go-nullary-fn-value-application](../decisions/2026-11-06-go-nullary-fn-value-application.md).
- **check-residuals (b): `Go.conv` Gom-decl rejection.** `gomOnly`
  ignored `Qual`, so `Con{Qual:"geom",Name:"Int"}` was admitted via
  the `*types.Go` fallback. `containsGomDecl` (recursive over
  `c.tyCons`) rejects declared Gom types at any depth —
  qualified/shadowed/nested — while `Go.*` constructor args stay
  traversable and the `List T ↔ Go.Slice T` pair rule is untouched.
  Reviewer proved the qualified-Con reject is free: `boundaryType`
  never maps qualified `Con`, so no provable conversion is lost.
- **check-residuals (c): deferred any-hole pin ADOPTED.**
  `(_ : String)`-style holes bound inconsistently eager-vs-deferred;
  now the hole meta unifies `hole := pt` and consumer pins on a
  standing deferred result are accepted via `unifyDeferredResult`
  (documented monomorphic narrowing). Decision:
  [any-hole-deferred-pin](../decisions/2026-11-06-any-hole-deferred-pin.md).
- **check-residuals (d): `checkBlock(e, bw)`.** `...any`-position
  blocks no longer stamp `Go.Any` onto the Block node — aligned with
  if/match/select/recordLit; the node-type-vs-last-stmt mismatch the
  `bw` comment worried about is removed on this side.
- **check-residuals (e): `.String()` audit closed.** E0401
  ascription / E0502 / E0507 now render via fresh `metaNamer()` +
  `types.Display` (`?1`-stable); E0502 verified unreachable from
  surface syntax (value-receiver `.M` defers to pendingSel), E0417
  `judgeT` reconfirmed concrete. TODO task closed.
- **wording-hygiene**: spec §8.3 `rune`→`Int32` honesty (`Char` is
  the literal/conv path), 3+-result arity cap written into
  §8.3/§8.4, §12 panic 2-part output made conditional on ≥1
  resolvable frame. `import alias "path"` + `.gomi`-side imports
  defined in spec §5/§7 (PROVISIONAL tags removed). gomtest root

  [gom-import-alias-and-gomi-imports](../decisions/2026-11-06-gom-import-alias-and-gomi-imports.md),
  [spec-suite-root-bare-gomi](../decisions/2026-11-06-spec-suite-root-bare-gomi.md),

## Review findings worth recording

- **Fresh-eyes review caught normative-doc overclaims for the
  fourth wave running** — but this time in the *docs* lane: the
  wording-hygiene branch wrote guarantees stronger than the
  implementation twice (generated import alias emit; interface-only
  cycles as E0606). Both were corrected to honest wording and the
  real work deferred to TODOs — a reminder that
  "spec-to-implementation" lanes can invert the same bug they fix.
- **Reviewer produced a wrong-in-mechanism suggestion that the
  worker corrected mid-fix**: lane 4's suggested
  `treesit-defun-skipper` predicate is a post-move hook, not a node
  filter — the worker found the real gate (`(REGEXP . PRED)` cons on
  `treesit-defun-type-regexp`). Reviewer mechanism-tracing catches
  bugs; worker mechanism-knowledge still arbitrates fixes.
- **Lane 1's review verified the quiet cases**: `containsGomDecl`'s
  qualified-Con rejection was proven *lossless* only by tracing
  `boundaryType` (it never maps qualified `Con`) — the kind of
  proof that makes a conservative oracle safe rather than just
  conservative. E0502's "unreachable" claim was mechanism-verified,
  not accepted.
- **Rate-limit death once again** (lane 2 reviewer); resume-after-
  reset completed cleanly — playbook holds for the fifth wave.
- **`.gitattributes` bit in-flight**: the lane-4 CRLF corpus entry
  lost its `\r` to `core.autocrlf=input` on first commit — caught
  when the new corpus test was added; fixed by marking corpus
  files `-text`. Line-ending-sensitive test fixtures need
  `.gitattributes` guards at creation time.
