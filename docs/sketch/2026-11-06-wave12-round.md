## What shipped

- **codegen-boundary (a): bound-name import alias always emitted.**
  `import "x/lib"` now emits `lib "x/lib"` unconditionally —
  the package-clause-mismatch hole (unqualified import + `lib.X`
  failing `go build`) is closed without needing a package-name
  oracle. 39 goldens regenerated (`fmt "fmt"`, `rt "…/rt"` …).
  Self-import exclusion verified (selfPath checked before imp()).
  Decision:
  [generated-import-bound-name-alias](../decisions/2026-11-06-generated-import-bound-name-alias.md).
- **codegen-boundary (b): `.gomi`-only cycles → E0606 with the
  path.** The loader's in-flight guard now carries the chain
  (`loading map[string]int` + `stack []string`); nested `.gomi`
  compiles reconstitute `ImportCycleError` from `data.cycle` so the
  entry gets the same path-bearing E0606 as `.gom` cycles. The impl
  scan deliberately still sees only `*.gom` edges — `.gomi` back-
  edges to non-mid-load packages are not cycles
  (`TestImplImportNoCycleWhenOnlyIfaceDepends` preserved).
  Decision:
  [iface-import-cycle-e0606](../decisions/2026-11-06-iface-import-cycle-e0606.md).
- **codegen-boundary (c): stray `.gomi` source registration.** The
  reported E0601 "no source registered" was actually the E0604
  stray-interface path — `gomiDecl` now returns the discovered
  file's bytes so `checkInterfaces` registers the source before
  emitting; the impl `iface.Package` gets `Name` wired so the
  previously-dead E0603 clause check works. Gaps entry corrected
  E0601→E0604 honestly.
- **codegen-boundary (d): `unknownCall` defensive diagnostic.** The
  unreachable 0-arg non-`-> T` fallthrough now reports `l.err`
  (E0901) instead of silently returning bare `fn`; the deferred
  `alwaysGom` replay branch is pinned by
  `TestDeferredAlwaysGomUnitMarker`.
- **codegen-boundary (e): spec §8.1 contrast** — `f ()` on
  `Unit -> T` (real Unit arg, `f(struct{}{})`) vs `-> T` (call
  marker, `f()`) written side by side.
- **lsp-multifile: package-granularity compile.** `gom lsp` gathers
  sibling `.gom` files per directory into a `build.CompileFiles`
  unit with standard LSP overlay semantics (open buffers shadow
  disk, unopened siblings read from disk, absolute `.gom` paths
  only). Diagnostics publish per member URI (unopened members via
  synthesized `file://` URIs) with departure retractions. Real
  Emacs+Eglot verified sibling resolution, cross-file hover,
  didChange flips. Per-change cost measured: ~48–50 ms with
  `import go` (`go list -export` dominates), ~0.1 ms without —
  loader session cache deferred. Decision:
  [lsp-package-unit](../decisions/2026-11-06-lsp-package-unit.md)
  (Supersedes the compile-unit part of lsp-v1-scope).
- **eval-forcing: ready-in-declaration-order.** `CheckInitCycles`'
  refset/vardep ported onto `check.Decl`
  (`internal/eval/initorder.go`); `Run` picks the earliest-declared
  all-ready var each step, cycle leftovers force in decl order
  (E9003 as before), `test` decls run after init, `main` last.
  Lazy forcing machinery untouched. eval-vs-compiled stdout pinned
  byte-for-byte incl. multi-file. Decision:
  [eval-init-ready-order](../decisions/2026-11-06-eval-init-ready-order.md).
- **interop-decisions (a): `*T` default = `Ptr T`** for derived
  views and extern declarations; `Option (Ptr T)` stays as the
  declaration override. `ResNilable` deliberately NOT extended to
  `*T` — it carries raw-type facts only, and the declared-strict
  meaning comes from `payloadNilGuard`'s verbatim-Equal
  conjunction, so extending it would add boundary panic to
  legitimate `(nil, nil)` returns. Decision:
  [ptr-t-default](../decisions/2026-11-06-ptr-t-default.md).
- **interop-decisions (b): `Go.Any` admitted as a first-class type
  spelling** at all type-expression positions (decision; impl
  pending — spec §8.3 is intentionally spec-ahead, recorded in
  gaps). Bare `any` rejected: lowercase idents are implicit type
  variables, so `fn f (x: any)` would silently re-read as
  polymorphic. `type T = any` aliases collapse to `Go.Any`;
  defined `type Token any` stays nominal. 5 impl TODOs + 5 gaps
  filed. Decision:
  [go-any-spellable](../decisions/2026-11-06-go-any-spellable.md).

## Review findings worth recording

- **Normative-doc overclaims caught for the FIFTH wave running** —
  lane 4's spec §8.3 asserted declared-result `Go.Any` boxing as
  normative while the decision itself left that undecided, and used
  `type Token = any` (a Go alias → collapses to `Go.Any`) as the
  example for a "nominal distinct type". Both fixed in-round. The
  pattern now covers impl lanes, docs lanes, and decision lanes:
  any lane writing normative text gets the same diff-vs-code check.
- **Reviewer probes found worse-than-reported failure shapes** —
  lane 4's recorded `Option Go.Any` gap was E0407 (clean
  diagnostic); a probe showed `Some 42` passes `gom check`/`gom
  build` and fails `go build` (type-invariant generic arg position)
  — a silent failure strictly worse than the recorded class,
  confirmed by the worker and filed as gap 4. Lane 3's "pure
  aliases are observably identical" was falsified by a fn-path
  reference loop; the worker re-verified with a type-correct
  variant and rescoped the residual to "lets lower turns into
  ValueAlias FuncDecls".
- **Reviewer caught a CI-gate violation the worker's green run
  missed** — lane 3's partial type switch on the `check.Expr`
  sumtype passes `go test` but fails `check-sumtype` (repo
  convention: partial probes are if-assert chains). Lesson for
  worker prompts: the big-three gate is not the whole gate —
  `scripts/check-sumtype.sh` is part of done.
- **CWD leak via URI shape** — lane 2's `untitled:scratch.gom`
  ended in `.gom`, so `packageMembers(".")` globbed the server
  working directory into the compile unit while two in-code
  comments claimed the shape was impossible. One-line `IsAbs`
  guard + a bait-file regression test that fails with the guard
  removed. In-code comments get the same overclaim review as docs.
- **Worker edited a forbidden ledger file again** (lane 1,
  `cba61b9` — TODO.md + gaps inside the branch) — content verified
  accurate by the reviewer and landed via squash; orchestrator
  ledger pass reconciled. Keep the rule; keep forgiving the
  accurate violation.
- **Workers verify reviewer claims before adopting** — lane 3's
  worker found the reviewer's counterexample program didn't
  typecheck, rebuilt a type-correct variant that confirmed the
  divergence, then rescoped honestly. Reviewer mechanism-tracing +
  worker mechanism-arbitration held again.
