## 学び

- `CallGo.FlatArgs` は実引数・callee の instantiated 型ではなく
  宣言型（rigid）を読む — `sig.Params` は `instantiateGoSig`
  済みで、型変数に関数型が代入されるとスロット arity が広がる。
  `Scope.run` の `body: Scope -> a` が `a = Int->Int` で arity 2
  扱いになる偽陽性は `declParamTypes` で解消した
- bare `CtorRef` は canonical curried chain（外側 arity 常に 1）
  を emit する — フィールド数は arity ではない。`Uncurry` は
  Atom でなく Expr なので、適応済み引数は tmp `Var` として
  `v.lets` 経由で解決する（#144 レビューで検出）
- ローカル let 多相の障壁は value restriction ではなく emission
  — Go にはローカル generics が存在しない。relaxed VR は
  「一般化の判定」の緩和で、着地問題とは直交する
