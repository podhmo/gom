# wave17 — 実行記録（round）

単独実行（子セッションなし・Devin Review がレビュー担当、podhmo がマージ）。

## lane 1 — `Go.fnN`（`Go.FuncN` 値 → Gom 関数値）

- PR: https://github.com/podhmo/gom/pull/35
- `Go.fnN f` で `Go.FuncN` の値を通常の（カリー化された）Gom 関数値に変換。直接 apply 案はコスト中で不採用。
- review 3 ラウンド: `Fn` 走査欠落（tail/tailrec の callGo walker が `c.Fn` を見ていなかった）、コンテナ内 int/int64 不一致の silent pun を E0510 化、method-iface ペイロードの `Option` wrap（import mapping の `(I,error)` ルールを `NilableSource`/`NilableGoRef` 経由で mirror）→ さらに verbatim seed との共存（`goFuncSeedRet` に `optWrap` を引数化）と `Result (Option T) GoError` → `(T,error)` の逆方向（`core.ConvOptToNil` + `option.NilOr`）を完備。Option ペイロードは nil-able な raw ビューに限定（`goRawNilable`: named 型は `NilableUnderlying` で underlying 判定 — `type S []int` や named empty interface をカバー）。
- 副産物: `check.NilableSource` プロトコル（goimport 実装 + gomimport 委譲）、`stdlib/option` の `NilOr`。

## lane 2 — loader セッション cache

- PR: https://github.com/podhmo/gom/pull/36
- `go list -export` を `os.UserCacheDir()/gom/goexport/<sha256>.json` に file cache — `gom check` の 2 回目以降で subprocess 0。`GOM_GOIMPORT_NOCACHE` / `GOM_GOIMPORT_CACHE_DIR` で制御。
- review 2 ラウンド: dep dir の srcStat 検証を追加（`-deps` を同じ subprocess で出力、依存 API は importer の .a に焼き込まれるため importer ソースだけでは鮮度を保証できない）、go.work 自動発見の key 化（`GOWORK=off` 含む）、gobin の `exec.LookPath` 解決（裸の "go" を `filepath.Abs` すると全 toolchain が同一 identity になる）。`Load("./foo")` 相対パスは `-deps` 出力の最終行を root と見る形に修正。

## lane 3 — 外部 module からの stdlib import

- PR: https://github.com/podhmo/gom/pull/37
- `gomimport.Loader.dirOf` のメインモジュール限定を撤廃: 外部パスは `go list -m -f '{{.Path}}|{{.Dir}}' all`（Config.Dir で 1 回実行）の最長プレフィックス + module-relative remainder で解決。パッケージ単位の `go list` は `.go` 未生成の Gom-only dir を拒否するためモジュール単位を採用。
- stdlib 短名 `import "list"|"option"|"result"` → `github.com/podhmo/gom/stdlib/<name>` に展開（`canonicalPath`）。生成される Go import は完全パス。
- `testdata/gocall` の手書き再帰 workaround を `import "list"` + `list.fold`/`list.is_empty` に置き換え — 外部 module から check/build/`go test` が通る e2e。
- 却下: embed .gomi で stdlib だけ特別扱い（生成 Go が結局 toolchain パッケージを import するので go.mod 依存は必須、`go list -m` 解決に一本化で十分）、opt-in フラグ。decision: `docs/decisions/2026-11-18-external-gom-imports.md`。
- spec 7 節更新、open-questions の該当項目を除去。
