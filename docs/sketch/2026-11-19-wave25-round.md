## 学び・次への申し送り

- builtin member module は `resolve.stdlibModules` への登録を忘れると unwired-compile 経路の E0201 note が嘘をつく（`Array` が未登録だった既存漏れを lane A で発見・同時修正）。登録済みになると「exposes no members yet」note は到達不能になるが、将来のモジュール追加時の防御枝として残してある
- `Ref a` は emit が `*T` でも `Ptr a` ではない: boundaryType が `Ref` を写さないので Go 境界の変換は一切ない。spec には「`*T` として渡せる」と書かないこと（lane A で一度誤記して修正済み）
- `Go.funcN` の seed 機構は field-write 直下では動くが `fn` 本体内部では `want` が届かない（E0407+E0510）。`tap` イディオムを使えるようにするだけならこの `want` 伝播接続だけで済み、`fn` パラメータ注釈（E0101）は必須ではない — wave26 lane 候補
- wave 中に発見した「`List a` セルへの `Ref.set` で W0501（境界コピー）」は `Ptr.set` と同じ境界ノイズ — Ref 固有の問題ではないが、可変セルにコンテナを入れると警告が出ることはガイド記事化の余地あり
