## What shipped

- **Hardening**: `x.M(1).N(2)` parses left-associatively
  (post-argument selector binds to the application); Float-inferred
  int literals materialize per-literal in codegen/eval/patterns; eval
  splices `..e` spread inside Go-call args (E0505 spread-sole-tail
  enforced eager + deferred); SourceMap/GoPos coverage (multi-input,
  same-basename, multi-line, `file:line:` edges); stdlib freshness
  gate (`fresh_test.go` recompiles `stdlib/*/` byte-exact); stdlib
  boundary tests + embed↔packages sync guard; E0415 quality items
  ①②④⑤ (single report per operand, `for` message reworded,
  quiet-meta cascade trim, all shadowed names reported); V-4
  leftovers (MinDecls sweep gate, deterministic witness tie-break,
  parseWant `->` rejection).
- **P3-2 residual + P3-6**: `Go.conv` legality now decided by a
  go/types oracle (`ConvertSource`/`GoConvertible` → `boundaryType`
  → `types.ConvertibleTo`; `gomOnly` shapes are disproof).
  Unresolved-meta conversion operands defer through `pendingConvs`
  and recheck after defaulting (`revisitConvs`) — same shape as
  pendingSels/pendingApplies. `containsShadowed` keeps the oracle
  out when any nested unqualified `Con` is shadowed. `ConvBoxAny`
  materializes numerics before `any()` boxing (`%T` gives `int64`).
  `testdata/gocall` exercises generated APIs from Go (ADT nil
  panics, zero-Result panic, Stringer assignability, copy vs
  non-copy slices, `%T`=int64) via `TestEndToEnd_GoCallsGom`.
- **V-6 residuals**: `pkg.Type.Ctor` member spelling (per-type ctor
  tables, multi-segment select+pattern); `.gom`↔`.gom` import
  cycles → E0606 scoped to cycle members (`implCycleSet`); `gom
  dump` package-aware; same-named sibling `test` blocks get
  deterministic `TestX_<fnv32a>` tags on collision; `gom build`
  withholds output on E0601/E0603 (package-unit all-or-nothing);
  exported `let foo`/`type Foo` collision → `var Foo1` + E0607 at
  the declaring package with an importer-side `EmitClash` net;
  `.gomi` audit bounded — polymorphic let members rejected E0602.
- **P5-1**: `Chan.*` (make/send/recv/recvOnly/sendOnly/close) and
  `Task` (spawn/await, panic re-throw, shared `taskBox`) via
  compiler-owned member tables → `rt` helpers. Go `chan`/`<-chan`/
  `chan<-` ↔ `Chan`/`RecvChan`/`SendChan` through `chanDirConv` at
  call boundaries incl. pipes (`core.ConvChanDir`); `struct{}`→`Unit`

  keeps `go`/`select`/channel-`for` as compiled-only by decision
