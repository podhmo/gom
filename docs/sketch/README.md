# sketch: 調査と検証の下書き

ネット検索などの調査結果や、prototype による検証結果を下書きとして置く。規範ではなく記録であり、決定は [decisions/](../decisions/)、仕様は [spec.md](../spec.md) が正。

- 1 件 1 ファイル。名前は `YYYY-MM-DD-<slug>.md` で、日付は**作成日**。内容を更新してもファイル名は変えない（リンクを壊さないため）
- 先頭に「目的」「関連（TODO の ID、decision の番号）」を書く。追記したら本文に更新日を書く
- 調査なら参照した URL と確認日、検証なら実験コードの場所（`experiments/` など）、手順、計測結果、結論を書く
- 結論が決定につながったら、対応する decision からこのレポートへリンクする
