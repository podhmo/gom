## wave の経過

wave54 で決めた継続行 hint と quiet recovery を先に実装し、その後で record candidate 表示・branch provenance・typo 候補の次段を固める順に進んだ。lane B/A/C は実装 lane、lane D/E は調査 laneだったが、両側で review が仕様の境界を狭める役割を果たした。特に lane C は provenance を「同じ expected type がそのまま供給される経路」に限定し、lane E は candidate source を closed な member table に限定した。lane C の review では spec harness が JSON を再エンコードして無関係な差分を出す問題が見つかり、byte stability を直した。

## 発見メモ

- grouping parens は AST node を作らないため、継続行らしさの判定に expression span の開始列を使うと実際の字下げとずれる。行の最初の visible token を見る必要があった
- 明示的な空 `notes` / `labels` は「確認しない」ではなく「空を要求する」。fixture update でこの配列を落とすと negative fixture が弱くなる
- `-update` が JSON を decode/encode し直すと、key 順だけでなく `->` / `|>` の HTML escaping まで変わる。診断 fixture は wire byte を保つ更新が必要だった
- quiet recovery では `wantT` を共有する後続式でも、no-match 側の独立 mismatch は消してはいけない。quiet かどうかだけでなく、どの制約が recovery artifact かを区別する必要がある
- E0407 の candidate declaration label は local record だけでは不十分で、import `.gomi` の declaration span がないと dependency record の label を出せない
- `Go.Map` / `Go.Slice` の operation table miss は constructor fallback 経路で出るが、diagnostic data 上は `namespace: "member"`。E0201 typo 候補の対象を `selectMember` だけにするとこの実用例を取りこぼす

## pitfall 一般化

- **診断 fixture の更新は構文ではなく wire を保つ**: JSON を意味的に再エンコードすると、コンパイラ出力と無関係な key 順・escaping 差分が review を埋める。fixture harness は compiler の wire order を保存し、必要な explicit empty assertion だけを最小挿入する
- **negative fixture は absence ではなく explicit empty で固定する**: 出てほしくない notes/labels/fixes は、フィールドを書かないと検証できない。空であることが仕様なら空配列を残す
- **recovery artifact は型へ bind せず quiet に残す**: `Unit` のような具体型へ bind すると、root error とは別の mismatch が後続へ伝染する。ただし independent mismatch まで消さないよう、quiet の伝播範囲は局所的にする
- **layout heuristic は AST ではなく visible source を見る**: 字下げは言語意味を持たないが、erroneous input への hint では見た目が大事。grouping や空白を AST shape から推測せず、最初の token 列を使う
- **候補表示は closed な同 namespace 集合から始める**: typo 候補を広い scope から取ると false positive の評価が難しい。まず module/operation member table のような小さく閉じた集合で距離規則を確立する
- **生成索引は生成元を直す**: `docs/error-codes.md` のような生成物を直接直すと sync test との往復になる。`internal/diag/codes.go` など source を直して generate する
