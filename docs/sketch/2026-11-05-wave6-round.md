Same protocol as Waves 4–5: one implementation agent per task, each
in its own managed worktree; a fresh reviewer per completed branch;
findings returned to the implementer (or applied by the orchestrator

squash merge after review. Implementers do not edit TODO.md /
open-questions.md / implementation-gaps.md / TODO-archive.md — they
report proposed ledger updates; the orchestrator applies them.

## Incidents worth recording

- **Rate-limit die-off, not stall**: 4 parallel `subagent_general`
  workers exhausted the plan-wide free-model pool — three died with
  **no completion notification** and unresumable transcripts
  (`read_subagent`/`resume` → "No subagent found"). No work lost only
  because they died before first commit; mitigation adopted was
  *fewer parallel workers* (2) + "commit WIP early" instruction.
- **Nanny experiment (failed approach, recorded)**: the idea was a
  sibling watchdog on a different model that sleeps through the rate
  window then resumes the dead worker. Findings: (i) custom profiles
  under `.devin/agents/` defined mid-session are not registered —
  spawn fails, so `nanny.md`/`probe.md` couldn't run this session;
  (ii) a `model: gpt` pin is rejected by the router anyway;
  (iii) even if it had run, cross-agent resume is impossible — dead
  transcripts are gone. The retained design in
  `.devin/agents/nanny.md` is reduced to a pure *timer*: sleep past
  the reset, exit, and let its completion notification wake the
  orchestrator to respawn a fresh worker from worktree state. It was
  never needed again after the concurrency cut.
- **`subagent_explore` shares the pool**: a reviewer died with the
  same free-model rate-limit error as `subagent_general` workers —
  the limit is org/plan-wide, not per-model. Reviewer respawned after
  the reset window; explore is still preferred for reviews (read-only,
  keeps the heavier write-capable workers unblocked).
- **Review-found fixes before merge**: initorder — `goimport`
  pipeline test bypassed the new package-wide init-cycle check
  (appended `lower.CheckInitCycles`), doc precision fixes (E0907
  `Spec:` field absent at the time, decision/gap wording), new
  hidden-tmp cross-file cycle test. p3-7 — `cal` wrap line off-by-one
  in the audit, strengthened the e2e assertion to check the wrapped
  file:line, fixture comment/usage nits. p5-2 — English paragraph
  localized in design.md, shared-`want` quiet-meta suppression risk
  now documented in code and the gaps ledger.

## Residual boundaries (recorded, not evaded)

- `@tailrec` R4 direct-reference graph is file-local — sibling-file
  mutual recursion escapes E0904 (same shape as the init-cycle bug
  fixed this round). Gaps ledger entry added.
- `metasIn(want)` quiet-marking can suppress a sibling arm's
  legitimate E0401 when an unresolved want is shared across conform
  positions — accepted tradeoff, recorded in gaps.
- W0701/W0702 coverage limits: `Chan.make` aliases, `Task.spawn`
  thunk captures, closure captures escape the lint; nested `go`
  duplicates a warning at the same span. Recorded.
- `Ptr T`: read-through works, no deref/nil-compare/construct —
  `errors.As` compiles then panics; `Option (Ptr T)` extern is the
  only nil-safe read (`*T` default question stays open). Problems doc
  + TODO task.
- `Go.Map` has no operations (`builtinGoMembers` names only);
  `Go.Any` unspellable in signatures hurt `json.Decoder.Token`;
  3+-result Go functions hidden while spec doesn't state an arity
  cap; `rune`→`Int32` (not `Char`) via `basicType`; `sort.Strings`
  compiles into a silent no-op. All recorded in gaps/TODO.
- P5-3 residuals: cons-construction combinators stay O(n²) — no
  reachable mutable-buffer path from `.gom` today (problem doc lists
  the options); `Fold`'s per-element closure is the arity-one
  value-representation consequence; `concat` trades O(1) stack for
  O(k) recursion (documented). `gom test` cannot forward `-race` —
  new TODO task.
