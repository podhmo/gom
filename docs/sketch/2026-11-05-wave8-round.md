## Starting point

`go1.27.0 linux/amd64`. Task prompts come from

## Work and review protocol

Same protocol as Waves 4–7: one implementation agent per lane, each
in its own managed worktree; a fresh read-only reviewer per completed
branch; findings returned to the implementer via `resume` (or applied
by the orchestrator when doc/nit-level); squash merge after review.
Implementers do not edit TODO.md / open-questions.md /
implementation-gaps.md / TODO-archive.md — they report proposed ledger
updates; the orchestrator applies them. Concurrency capped at 2
implementation lanes (rate-limit incident history).

## What shipped

- **error-boundary**: a lone Go `error` result admits three declared
  views — `Result Unit GoError` (type-derived default), `GoError`
  (never-nil claim, verified at the boundary by a generated nil-check
  panic via the new `ErrorFromGo` core node + `GoResultsErrValue`
  shape), `Option GoError` (nil-able value — the `GoResultsNil` gate
  widened from `*T` to `*T`/`error`). Standard bindings live in a
  compiler-curated table `internal/goimport/stdbind.go` sharing the
  extern admission machinery: `errors.New`/`fmt.Errorf` → `GoError`
  (variadic `...any` works end-to-end), `errors.Join`/`errors.Unwrap`
  → `Option GoError`; explicit extern overrides restore the default.
  `errors.Is`/`As`/`Unwrap`/`Join` verified end-to-end
  (`testdata/realworld/errwalk`, `Ptr.new` targets incl.
  `*rt.StepError`). `|?>` wrap frames are `rt.StepErr("step", err)` /
  `*rt.StepError{Step, Err}` — same rendered text, `Unwrap` preserves
  `errors.Is`/`As`, `Step` is `errors.As`-readable. spec 9.2 example
  fixed (`Result Int GoError`). Two decisions adopted
  (error-result-bindings, result-pipe-wrap-frame).
- **soundness-bugs**: `Go.conv` `Go.Slice T ↔ List U` with
  non-`types.Equal` elements rejected E0507 at `convOK`
  (`sliceListPair`) — the aliasing pun is closed; literal range check
  E0417: `pendingLit` records expr/pattern literals, `revisitLitRanges`
  judges at the post-default static type (direct unary `-` operand
  signed, direct `Go.conv` operand at target incl. float→integer
  `constant.ToInt` rule, floats must be float64-representable);
  `checkInterfaces` `.gomi`-input key cleaned (real mechanism:
  `gomiInputs[want]` miss → double compile/dup diagnostics — the
  recorded `.gom`-group split was a misdiagnosis since `filepath.Dir`
  already cleans); W0501 peels `Conv` ascribes on inline
  `Go.conv e : Go.Slice T` args.
- **diag-fuzz**: E0904 `through`/`path` renders hidden VarDecls via
  `nodeName`/`DiagName`; E0407/E0409/E0801 renumber metas per
  diagnostic (`?1…`); issue #11 fixed — `CallUnknown` now consumes
  `CallInfo.ArgToParam` (saturated → decl-order chain, non-prefix
  labeled fills → `closureChain` η-expansion matching eval, unstable
  callees `tmpBind`ed once); issue #12 fixed — `selectEscape` wraps
  `(`-led (and `nb`-`{`-led) Select-arg receivers in `(...)`,
  restoring format idempotency. Both knownBugs registrations removed;
  corpus seeds now live pins.
- **boundary-aliasing**: H1–H7 verified with real fixtures
  (`testdata/gocall/boundary`+`box`) — value-struct field reads
  detach (H1), `Ptr` reads observe Go writes (H2), `[]T` fields read
  as `List T` via a per-read copy with `[][]int64` stopping one level
  deep at `List (Go.Slice Int)` (H3 refined — neither E0501 nor
  Go.Slice), field writes are unspellable (H4), exported `let`s are
  writable Go package vars — element-write AND wholesale rebind —
  and `List` params cross the generated API verbatim (H5
  confirmed+stronger), records are value copies with shared
  List-payload backing (H6), variants are *value* structs behind the
  sealed interface (H7 refined). MoonBit visibility corrected to the
  4-kind model; OCaml record/FFI sharing confirmed from official
  docs. Two contract gaps filed in the ledger; the §8.7 contract
  decision is queued as a wave-9 task.

## Incidents worth recording

- **Rate-limit die-off (twice, mitigated)**: the first error-boundary
  worker died to the org-wide free-pool exhaustion — but its
  uncommitted WIP was salvageable (the draft decision
  `2026-11-05-error-result-bindings.md` was already ~complete plus
  the core `ErrorFromGo` extension); the orchestrator committed it as
  `3badb89` and a fresh worker resumed from worktree state and
  finished the whole lane. A second pool hit ~04:30 UTC blocked a
  review-fix resume; work continued after the 06:16 reset. Lesson
  reinforced: commit WIP early — here even the *uncommitted* state
  was recoverable because the orchestrator committed it for the dead
  worker.
- **Recorded misdiagnosis corrected by review**: the wave7-registered
  "`checkInterfaces` groups by `filepath.Dir` without Clean → `.gom`
  group split" claim was wrong — `filepath.Dir` already Cleans
  internally, so `.gom` grouping was always correct. The real hole
  was the `.gomi`-input key (`gomiInputs[want]` miss → double
  compile + duplicate diagnostics). The record (gaps entry, TODO
  text, test comments) now carries the corrected mechanism plus the
  misdiagnosis history — the kind of failed-approach record this
  process is meant to keep.
- **Review-found fixes before merge**: error-boundary — stale
  `fmt.Errorf` wrap wording in 6 places (spec/design/call.go/
  emit.go/SKILL docs now say `rt.StepErr`); E0509 user-facing
  explanation still showed the pre-views admission table; missing
  unit tests for stdbind/ErrValue (added: stdbind_test.go,
  validate ErrValue invariants, lower goResultsOf pins, negative
  spec fixtures). soundness-bugs — LitFloat `Go.conv` operand to int
  target skipped judgment (`1.5 : Int32` → `int32(1.5)` build fail);
  now `constant.ToInt`-judged (truncation vs overflow reported).
  diag-fuzz — `{`-led Select receivers escaped under `nb` (same
  spec-1.7 class as issue #12; `selectEscape` now nb-aware), missing
  `unknownCall` unit test added.

## Residual boundaries (recorded, not evaded)

- `(error, error)`-style results let a first-position nil error ride
  into the `Ok` payload unchecked — same family the lone-error views
  closed, explicitly scoped out by the decision; TODO bug + gaps entry.
- `Go.conv` literal operand at a *named* Go type skips range judgment
  (`Go.conv 5000000000 : os.FileMode`, `Go.conv 1.5 : time.Duration`
  → build-failing emitted Go). Needs an oracle underlying-kind query
  or a lowering-side escape; TODO bug + gaps entry.
- E0701 Meta arm still leaks raw `?n` (same class the E0407/9/E0801
  fix closed; TODO task).
- `reclassifyCalls` nils `ArgToParam` past declared arity — possible
  eval-vs-compiled divergence, unconfirmed; TODO `[bug?]` entry needs
  a reproducing case first.
- CLI still doesn't run extern checking (E0509); the declared views
  widened the blast radius (arity drift now shapes codegen). Gaps
  entry updated with a fresh example.
- `errors.As`-family "any that must be a non-nil pointer" contract
  can't be spelled — open-questions entry (typed binding vs lint).
