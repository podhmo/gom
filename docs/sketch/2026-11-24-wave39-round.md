## 学び

- **abstract `type X` は `.gomi` 専用の構文**: `.gom` に書くと E0101。
  再生成が著者の起点になる設計では「abstract のまま残る宣言だけ」
  という条件分けは成り立たない — directive の引き継ぎは同名の型
  宣言全体へ適用するのが自然（wave39 lane D の spec 修正）
- **reshape で値を rebuild するときは payload メタを全部写す**:
  `VVariant` の `Ctor` を落とすと `builtinDeclCtor` 経由の後続抽出が
  壊れる。rebox の round-trip fixture が差を捉えた
- **`//gom:allow` は error のみ warning を落とせない**: demote は
  error→warning 方向のみ。warning opt-out が要る lint は設計に
  `//gom:allow` 拡張を織り込む必要がある（wave39 lane C）
