## lane 3 — `.gomi` の多相 let

- PR: https://github.com/podhmo/gom/pull/42
- 採択（podhmo）: (a) 許す。
- `.gomi` の `let` シグネチャで型変数が書ける — `let empty : List a` が一般化された値を公開。
- `resolve.Symbol.Thunk` を新設し thunk oracle を import 越しに運ぶ: member table が `() -> T`+`TypeParams` で mint、check の `valOf`・lower の `funcRefOrFlatten`・lint がローカル map と OR 判定。
- `p.empty` は値として型付き、`p.Empty[T]()` を emit — multifile fixture で `List Int`/`List String` の両 instantiate を `go run` で検証。
- review finding 修正（b4ea588）: 関数型の多相 let（`let ident : (a) -> a`）を thunk mint すると `types.Fn` が `() -> (a -> a)` を `a -> a` に flatten して引数が消えるため、Func-typed let は通常の fn メンバー（DeclArity 付き）として mint — fixture `shapes.ident` で pin。
- decision: `docs/decisions/2026-11-18-gomi-poly-let.md`。
