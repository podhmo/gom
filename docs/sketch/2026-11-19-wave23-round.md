## 学び・次への申し送り

- `@extern fn` のシグネチャは生成呼び出しと完全一致が必要 — `Go.func2 f` の結果型は `Go.Func2 ... Go.Any GoError` で、extern パラメータを `GoError` 終端にすると実装 fn が `Result Unit GoError` を返す形に合う（E0401 でずれる）
- 非 main パッケージの実験 fixture は `<pkg>.gomi` が必須（E0601）— `gom info -o <dir>/<pkg>.gomi <dir>` で草案を生成して公開 API に絞る
- `experiments/w23/*/go.mod` は `replace github.com/podhmo/gom => ../../..` で入れ子モジュール化 — CI の check-experiments が vet+test を走らせ、TestRepoFiles はパースしない `.gom.txt` をスキップするので構文モックはその拡張子で置く
