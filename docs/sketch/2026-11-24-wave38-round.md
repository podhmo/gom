## 学び

- **`*types.Go` は「named」であって「slice」とは限らない**: named
  empty interface（`json.Token`）も `*types.Go` — 形の分岐には
  underlying の種類を oracle に問う必要がある（`GoUnderlyingIsSlice`）
- **宣言型の名前は builtin 名と衝突しうる**: `type Int`/`type Result`
  のようなローカル宣言が `switch t.Name` の builtin case に誤って
  流れる — 宣言チェックは名前 switch より前に置く
- **地図アクセスは必ず `ok` イディオム**: `tyCons[key].sym` は
  map miss で nil deref — `if ti, d := m[k]; d && ti.sym != nil`
- **`-update` の回帰チャーンは毎回 revert**: golden/spec の
  `-update` は無関係 fixture の空白を書き換えるので、コミット前に
  `git status` で範囲を確認する
- **check の判定と emit の意味は別々に間違いうる**: lane E は
  check 側が正しかったが emit がコピー規律を破っていた —
  「受理するか」と「どう emit するか」は独立に検証する
