# gom 探索者プロンプト（定期実行用）

以下は「gom で普段使いツールを書いて領域地図を更新する」探索を定期的に回すためのプロンプト。
`---` の内側をそのままセッションの最初の指示として使う。`{前回のrun名}` は
その時点の sandbox/ の中身を見て埋める（初回は不要）。

---

あなたは探索者です。gom で実用的なコードを書き、得意領域・不得意領域・
明らかに無理な危険領域を観測・記録してください。

## 作業場所とコミット

- `sandbox/` ディレクトリで作業する。run ごとにサブディレクトリを切る
  （例: `sandbox/r2-xxx/`）。過去の run の成果物は読むが変更しない。
- 生成される `.go` ファイルはコミットしない（`sandbox/.gitignore` で `*.go` を
  無視済み）。`go vet` / staticcheck が生成コードを検査するため。
- コミットは好きなタイミングで。最終的に squash merge するので粒度は自由。
- 完了したら PR を作る（マージは人間が行うのでこちらではしない）。

## 手順

1. **アイデアメモ**: gom のことは考えず、「Go で普段作るカジュアルなツール」を
   何個かメモする（sandbox/ideas.md を参考に、重複しない題材を選ぶ）。
   今回は特に {前回のrun名} で試した領域と違う題材を優先する。
2. **スキル有効化**: `.gom` を書き始める前に `gom-agent-guide` スキルを読む。
   OCaml/F#/Go の習慣で書くと構文を間違えるため必須。
3. **実装と検証**: 各ツールは `gom check -format text` → `gom run FILE -- args`
   で実動作確認（実在コマンドとの比較が理想: wc, sha256sum, curl 等）。
4. **ストリーミング記録**: 発生したエラー・不足機能・迂回・諦めを雑でいいので
   `sandbox/log.md` に時系列で追記していく。後で清書しない。素のまま残す。
5. **諦めの保全**: 数回試行錯誤して無理なら諦める。そのときの状況とコードを
   「第二の財産」として残す（動かないコードもファイルとして残す）。
6. **領域地図**: 最後に得意/不得意/危険の3分類でまとめ、log.md に書く。
   前回の領域地図があれば、追認・修正・新発見の形にする。

## 記録してほしいもの

- すんなり書けたもの（成功記録 = 第一の財産）
- エラーメッセージと解決法（E0101, E0401 等のコード付きで）
- 迂回したもの・回復不能だったもの・諦めたもの（状況とコード）
- sum types / pattern match がうまくはまった場面
- 「仕様・実装・文書のずれ」に見えたもの → `docs/implementation-gaps.md` にも登録

## 既知の罠（再確認の手間を省くため、踏む前に読む）

- ネストした nullary パターンは括弧が要る: `Ok (HelpA)`
- 式が終わりうるところの改行は式を分割する
- `+` は数値専用。文字列は `${}` 補間
- `List.get (index) (list)` の順。`List.sum` は Float 専用
- ビット演算子なし。フラグ合成は `+`（互いに素なビットのとき）
- `Go.conv` で List→named slice は check を通って go build で落ちる（ずれ）
- `Ptr` field 代入 `ptr.Field = v`、`let x : T = e` が注釈位置
- composite literal はない → `Ptr.new` + field 代入で作る
- `@method` は `serve_http`→`ServeHttp`。`ServeHTTP` 等の initialism は出せない
- `import _ "pkg"`（blank import）は構文エラー。`//go:embed` も不可
- 8進数は `0o644`（`420` だと staticcheck SA9002 で CI が落ちる）
- 部分適用の Unit 残り関数値は Println に渡すと `0x...` になる
- `pkill -f` は自分のシェルのコマンドラインにもマッチするので PID で殺す

テキスト処理 / CSV・JSON / 日時 / ファイルシステム / ネットワーク /
並行・並列 / プロセス起動 / HTTP サーバ・クライアント / テンプレート /
正規表現 / CLI flag / 文字エンコーディング / シグナル・タイマー /
